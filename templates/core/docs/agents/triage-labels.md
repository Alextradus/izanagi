# Libellés de tri

Les skills parlent de cinq rôles de tri. Ce fichier fait correspondre ces rôles aux libellés du tracker de ce dépôt.

| Libellé dans mattpocock/skills | Libellé dans notre tracker | Sens                                                |
| ------------------------------ | -------------------------- | --------------------------------------------------- |
| `needs-triage`                 | `needs-triage`             | Le mainteneur doit évaluer cette issue              |
| `needs-info`                   | `needs-info`               | En attente d'informations de la part de l'auteur    |
| `ready-for-agent`              | `ready-for-agent`          | Entièrement spécifiée, prête pour un agent autonome |
| `ready-for-human`              | `ready-for-human`          | Demande une implémentation humaine                  |
| `wontfix`                      | `wontfix`                  | Ne sera pas traitée                                 |

Quand un skill cite un rôle, par exemple « apply the AFK-ready triage label », prendre le libellé correspondant dans cette table.

Pour changer de vocabulaire, modifier la colonne de droite.
